## 0. 结论先行

第一轮修掉的是"**聚合数学与数据接口**"（n² 加权 / 探针 held-out / 聚合顺序）。
第二轮发现不到位的地方集中在"**信任层、激励层、法律层的实证水位比设计稿假设的低**"：

## 2. 四个新推导（可复算）

### 推导 5：尺度攻击为何必须"信任锚"，clip 为什么不够

设聚合 θ ← θ + Σ_i p_i·Δ_i（FedNova 归一化后）。恶意节点提交 Δ_evil = k·g（k≫1）：

```
朴素加权平均：攻击者把 k 调到使 p_evil·k·‖g‖ > Σ_{i≠evil} p_i·‖Δ_i‖ 即主导全局
clip(‖Δ‖≤C)：合法 Δ 的尺度 ∝ η·E_ref·‖∇f_i‖，随数据量/曲率变化；
              固定 C 要么误伤大贡献者（假阴），要么放过放大 k 倍的攻击（假阳）
              且 clip 不改方向——投毒的方向问题它一律不管
```

**FLTrust 修法**：服务端用 root dataset D_r 从**同一 θ₀** 训 E_r 步得参考更新 Δ_s，则

```
TS_i := ReLU( cos(Δ_i, Δ_s) ),   Δ_i ← TS_i · ‖Δ_s‖ · Δ_i/‖Δ_i‖・p_i
θ ← θ + Σ_i Δ_i
```

- **尺度不变**：归一化后 k 倍放大不再改变贡献（TS 与 ‖Δ_s‖ 都与 Δ_i 幅值无关）；
- **方向相反者被 ReLU 归零**（cos<0 ⇒ 0 权重）；
- **本项目的免费 root dataset**：F-INV-6 切出的探针窗（全网 1% 共享数据）**就是** D_r
  ——不新增数据管道、不破"原始数据不出本地"。探针窗的第一个身份是 held-out 评测，
  第二个身份是 FLTrust 锚。

**失效模式（FoggyTrust 2026 实证，必须照抄进诚实边界）**：D_r 与客户分布严重不匹配时，
诚实的 non-IID 客户也会拿低 TS。⇒ 本设计落地约束（ADR-018）：TS **只用于异常检测与降权**
（TS≈0 ⇒ 记入账本 + 逐步降权），**不用于把 Δ_s 方向当唯一正确方向放大正常更新**；
同质档默认关，仅 L2（公开房间）开启，且开启时同步记录 `rootDatasetHash`。

### 推导 6：女巫拆分在归一化账本下零收益

聚合对节点更新是**线性**的。一个节点把同一份数据/同一份算力拆成 m 个身份，各持 1/m：

```
归一化前：Σ_j p_j·Δ_j，p_j = (1/m)w_i/Σw = p_i/m  ⇒ 合计 = p_i·Δ_i（与拆分无关）
FedNova 后（每份 E_j = E_i、seed/数据相同）：s_j = s_i
          ⇒ Σ_j p_j·s_j·Δ_j = p_i·s_i·Δ_i（仍与拆分无关）
代价：上传 ×m、账本条目 ×m、被抽检概率 ×m（冗余复算反而更容易暴露）
```

⇒ **结论一**：贡献与聚合维度上，拆分收益为零；这在 **effective-share 归一化（INV-19）** 之后
自动成立——第一轮修的 FedNova 顺手把女巫攻击的"刷贡献"动机也消掉了。
⇒ **结论二**：有收益的只剩**投票权**（按节点数计一票时）。∴ 治理投票必须按
`effective share` 加权而非按节点数（落点 11 §6）。
⇒ **边界**：root/账本由单一权威裁定时，权威本身偏袒 m 个身份无法从账本看出
⇒ 仍需 per-IP/AS 软上限与 L2 身份（开放问题⑤），但那是"权威作恶"，不是"成员作恶"。

### 推导 7：探针增益 = 可复算的有效贡献（LOO ↔ 一阶 TDA）

设 u(θ) = 探针池上的指标（分钟级可测，11 §2.4）。节点 i 的本轮归一化贡献为 s_i·p_i·Δ_i：

```
LOO 贡献：φ_i := u(θ) − u(θ − s_i p_i Δ_i)        （精确但每节点一次重训，O(N) 太贵）
一阶近似：φ_i ≈ ∂u/∂θ · s_i p_i Δ_i = s_i p_i · ⟨g_u, Δ_i⟩,  g_u := ∇u(θ)
```

- 全网**同一个 g_u**（一次反向）⇒ O(N) 次内积即可得全部 φ_i ⇒ 可复算、可审计；
- 这正是 TracIn/TRAK 的一阶形式（arXiv:2410.17413 证明 8B/160B token 规模可行）；
- 性质：近似零和（Σφ_i ≈ u 的预期改善）但**不保证每项为正**，且
  Maverick-Shapley（TMLR 2025）证明稀有数据持有者短期 φ_i 常为负、长期不可替代
  ⇒ 账本用滑动窗口/EMA，**禁止单轮 φ_i 定生死**；
- 脆弱性（arXiv:2509.19921）：φ_i 依赖聚合架构与聚合规则版本 ⇒ 账本必须记
  `aggregationRuleId`，否则跨版本分数不可比（落点 11 §4，ADR-019）。

### 推导 8：`perturb` 把通信压力转成聚合端算力（通信预算的新维度）

`perturb` 每节点只传 O(1) 字节，但聚合端要为每个 seed 重建方向：

```
grad/delta：通信 O(S·P)，聚合 O(S·P)
perturb   ：通信 O(1)，聚合 = 重建方向 O(P) + 合成 O(S·P)（内存驻留 θ+δ）
EGGROLL 低秩：δ = A_{r×d}·B_{r×d}ᵀ 由 seed 生成，重建仍是 O(P)，但无需传输
```

⇒ 判定式（plan() 新预算项）：`S·P·4B ≤ agg_compute_budget` 才允许聚合端重建。
S=100、P=1M ⇒ 每轮 400MB 驻留、可接受；S=1000、P=30M ⇒ 4.8TB/轮，**必须分层聚合**
（peer 子群各自合成再上报 `local-delta`）——这是 FED-V13 星形约束的算力版。
落点：09 §4.0 通信表加"聚合成本"列、07 §5 `chooseStrategy` 加聚合端预算输入、
STR-V14 验收（构造 S·P 超限 ⇒ plan() 拒星形 perturb 聚合并给分层建议）。

## 4. 明确不做 / 暂缓（防范围膨胀）

- **不做** ZK 训练证明进承诺（VFT 证明 PEFT 级可行：16.8–31.2s/步、验证 <200ms——
  但那是单机 LoRA 微调；联邦多方训练证明仍是开放问题，列远期路径，不上路线图）。
- **不做** Data Shapley 作为激励主路径（O(2^N)；GTG/Owen 近似 + LOO 一阶近似已够用，
  列为 P10 后研究项）。**不做** DP 的隐私预算会计学（只用最简裁剪+高斯噪声开关）。
- **不做** PoP/生物特征身份（采用摩擦被 Frontiers 2020 综述与 TBFL 双重证实过高；
  L2 用 DID/VC 式可撤销凭证足起步）。
- **不追** TIGER 类攻击的军备竞赛（记录威胁、给分层防御与触发条件即可；
  我们的默认场景是"自己人的房间"，攻击面随 L2 开放线性增长——所以防御也随 L2 分级开放）。
