## 2. 六个新推导（可复算）

### 推导 15：稀释攻击与拜占庭偏置的不可消除性

设聚合 `θ ← θ + Σ_i p_i Δ_i`（FedNova 归一化后）。诚实集 `H`（|H|=n−f），拜占庭集 `F`（|F|=f）。

**① 无防御时攻击者可任意支配**

```
诚实项：‖Σ_{i∈H} p_i Δ_i‖ = p_H·‖ḡ‖，  攻击项 ≤ Σ_{i∈F} p_i‖Δ_i‖（无界）
⇒ 攻击者取 ‖Δ‖ → ∞ ⇒ 聚合结果任意 ⇒ 无界攻击下"容忍 0 个拜占庭"
```

**② 限幅（‖Δ_i‖ ≤ C）把偏差压到 O(f/(n−f))**

```
偏差/信号 ≤ (f/n)·C / ((n−f)/n·‖ḡ‖) = (f/(n−f))·(C/‖ḡ‖)
⇒ 偏差随拜占庭比例 f/n 线性增长，与 n 无关（固定比例时）
```

**③ trimmed-mean 的精确系数（Zenodo 2026 的 sharp 结果）**

```
每侧 trim f 个： κ*(T_f; f) = f/(n−2f)
 n=7,  f=2 :  κ* = 2/3 ≈ 0.67
 n=10, f=2 :  κ* = 2/6 ≈ 0.33
 n=21, f=2 :  κ* = 2/17 ≈ 0.12
⇒ 要把攻击者可平移的倍数压到 0.1 以下，需 n ≳ 20f（远严于 Krum 的 n≥2f+3）
```

**④ 信息论下界（Yin et al. 2018）与去中心阈值（ByzSGD）**

```
任何算法的误差 ≥ Ω( α/√n + √d/√(nm) )      α=拜占庭比例，d=维度，m=机器数，n=每机样本
  · 第一项 α/√n 是拜占庭**偏置**：随 α 线性、对 n 只按 1/√n 缓降 ⇒ 不消失
  · 第二项是正常机器的统计方差
完全去中心（无聚合权威，参数服务器也分布）：ByzSGD 证明 n_ps>3f_ps+1 ∧ n_w>3f_w 可解且**渐近最优**
⇒ 一律存在阈值；"容忍"必然付精度代价
```

**设计结论**：

1. **01/10 的"不需要信任任何一台设备"必须改写**为：
   *"容忍不超过阈值比例的拜占庭节点，且精度代价与拜占庭比例成正比（可量化、可记账）"*；
2. **去中心档（gossip / 多聚合端）的拜占庭阈值是 1/3**——这比有聚合端的 1/2 更严，
   必须写死进 L2/L3 门票（否则"去中心"成了安全性的**降低**而不是提升）；
3. **`plan()` 应把"拜占庭预算"变成显式输入**：给定期望容忍 `f/n`，反算所需房间规模
   （由 κ*=f/(n−2f) 给出）与预期精度代价——**人不能凭感觉决定房间要几个人**。

### 推导 16：自报权重的份额膨胀（本轮最锋利的一条）

**现状**：`Update.weight := 样本数/token 数（名义加权用）`（09 §4），
"自报 + 静态校验"（11 §4）。聚合：`p_i = w_i/W`，`s_i = E_ref/E_i`，`e_i = p_i·s_i`。

**同速情形**（`E_j ≡ E` ⇒ `E_ref = E` ⇒ `s_i ≡ 1`）：

```
e_i(c) = p_i(c) = c·w_i / (W_{-i} + c·w_i),      W_{-i} = W − w_i

原始份额 w_i/W = 10%  ⇒  节点把自报样本数 ×10（c=10）：
    p_i = 1.0W / (0.9W + 1.0W) = 1/1.9 = 52.6%
  ×100:  p_i = 10W/(0.9W+10W) = 91.7%
  ×→∞ :  p_i → 100%
```

**代价**：零。**证据**：无。**检测**：无（`weight` 无任何外部约束）。

**为什么 FedNova 救不了**（第一轮的修复在这里失效）：

```
FedNova 归一化： s_i = E_ref/E_i  —— 修的是 **steps 维**（E_i）
本漏洞在 **weight 维**（w_i）：  p_i = w_i/Σw  —— 归一化对 w_i 不设防
⇒ 第一轮把"n² 加权"修掉了，却没注意 n 本身是自报的
```

**连带后果**（比份额失真更严重）：

- 11 §4 的三列账本（nominal / effective / probeDelta）**全部以 p_i 为基**⇒ 三列同时失真；
- 11 §6 治理"投票权按 effective share 加权"**被同一个字段操纵**⇒ 治理被单节点夺取；
- 09 §5.5 账本"双份额"防的是"显示在、实际被抹掉"，**没防"显示本身就是假的"**；
- 09 §5.0.1 的 IPW 修正 `w_i ← w_i/E[q_z]` 同样以自报 w_i 为基 ⇒ 一并失效。

**然而，权重是**可以**推导出来的**——设计里本来就有推导所需的全部数据：

```
数据面（均已存在且内容寻址）：
  11 §2.6 的块表（block table）：节点 i 被分配的块集合 S_i 是 dataVersion 的确定性函数
  03 §2.2 的覆盖簿（coverage ledger）：{shardId → {trained, claimedBy}}
⇒ weightDerived_i := tokens(S_i) × min(steps_i, E_max)
     其中 steps_i 由 FedNova 已有的 `Update.steps` 提供，E_max 是本轮时间预算上限
     节点**不能**超过自己持有的数据量（F-INV-2 保证数据不出本地 ⇒ 上限是 assignedShards 的 token 数）
⇒ 上界可验证；下界由覆盖簿的 committed bitmap 交叉核对
```

**修复（ADR-030 / INV-23）**：

1. `Update.weight` **降级为 advisory**（仅用于异常检测/诊断），**不得进入聚合的 `p_i`**；
2. 聚合与账本的 `w_i` 一律用 `weightDerived_i`；自报值偏离推导值超容差 ⇒ 记 `WEIGHT_MISMATCH` 入账本；
3. 验收：**自报 ×10 不得改变 effective 份额**（FED-V21）——这是本轮最该有的一条"红/绿"用例。

### 推导 17：有偏压缩的偏置地板与 error feedback 的几何衰减

**无 EF 时**：有偏压缩器 `C`（top-k / sign）。令压缩误差 `e_t = x_t − C(x_t)`，`E[e_t] ≠ 0`。

```
发送 C(g_t) = g_t − e_t
⇒ E[每步更新] = E[g_t] − E[e_t] ≠ E[g_t]     （偏置固定，不随 T 衰减）
⇒ 在 PL/凸条件下收敛到 O(‖E[e]‖) 的**邻域**，而非最优点
⇒ 这就是 EI21 之前"top-k 不收敛"的原因；Karimireddy et al. 明确 EF 是必要条件
```

**量化读数**：设梯度坐标按幂律衰减，top-k 保留比例 `k/d`。被丢弃的尾部质量
≈ `(k/d)^(a−1)`（a 为幂律指数）。`k/d = 1%`、a≈1.2 时，`E[e]` 可达 `‖g‖` 的**百分之几**——
**每步注入固定偏置**，在几千步的预训练里不是一个可以忽略的项。

**有 EF（EF21）时**：

```
r_t = r_{t-1} + g_t − C(r_{t-1} + g_t),   发送 C(r_{t-1}+g_t)
EF21（arXiv:2106.05203）：非凸 O(1/T)，PL 条件下**线性**收敛
⇒ 残差 r_t → 0，偏置被"记账"而非丢弃
```

**本设计的三个缺口**：

1. **协议缺字段**：`Update`（09 §4）没有 EF 残差 ⇒ 09 §5.1.0 引 SparseLoCo
   作为带宽解，却**没把 SparseLoCo 赖以成立的 EF 带进来**——借了结论，丢了前提；
2. **状态所有权未定**（Zenodo 2026 的关键点）：**服务端必须存"压缩快照"，
   不得把量化误差递归回灌真实动量状态**，否则误差相乘放大。
   ⇒ 必须写死"**残差在客户端、压缩快照在服务端；两处都不得持有对方的真实量**"；
3. **持久化未定**：EF 残差是**跨轮持久状态**。节点切后台/重连/从 Snapshot 恢复，
   若残差丢失 ⇒ 相当于把 EF 关掉（回到偏置地板）。
   ⇒ 与 **INV-13**（快照必须含数据游标）同构：**快照必须含压缩状态**（INV-24）。

**修复（ADR-032 / INV-24）**：`Update` 增 `efState?`（或由节点本地维护 + 快照携带）；
`Snapshot` 增 `compressionState`；解压/压缩两端的所有权写死；STR-V17 + ENG-V11 验收。

### 推导 18：同质档的收敛邻域（把"有保证"写成可检验的式子）

**Li et al. 2019/2020（arXiv:1907.02189）**，E 步本地、全参与：

```
E[F(w_T)] − F*  ≤  (2κ/(γ+T))·( B/μ + 2L‖w_0 − w*‖² ),   κ = L/μ,  γ = max{8κ, E}

B = Σ_k p_k² σ_k²   +   6LΓ   +   8(E−1)² G²
    └─ 噪声/参与不均衡 ─┘  └─ 异质性 ─┘  └─ 局部步数漂移 ─┘
```

三项的**性质完全不同**，必须分开读：

| 项 | 来源 | 随 T 消失？ | 对本项目的含义 |
|---|---|---|---|
| `Σ_k p_k² σ_k²` | 随机梯度噪声 × **样本加权** | 否（常数项） | **部分参与 + 样本加权**下噪声按 `Σp²` 而非 `1/n` 收缩 ⇒ 少数大节点主导方差 ⇒ 又是"权重必须可信"的第三个理由 |
| `6LΓ` | **数据异质性**（梯度差异 Γ） | **否** | 房间的接受度判据（见下） |
| `8(E−1)²G²` | **局部步数 E 的漂移**（**二次**） | **否** | 时间预算截断让快节点多跑（09 §5.5 的同一现象的另一面）：FedNova 修的是**加权**，这一项修的是**漂移本身**；只有 `E→1` 或 `η→0` 才消 |

**⇒ 正确的声明**（替换 09 §2.1 的"有保证（= 经典联邦收敛）"）：

> 同质档收敛到由 **(a) 噪声×参与不均衡 + (b) 数据异质性 Γ + (c) 局部步数漂移 E²**
> 三项之和界定的**邻域**，最优点不是可达的（除非 η→0 且 E=1）。
> 收敛**速率**是 O(1/T)，**精度**由邻域决定——两件事不能混为一谈。

**房间可接受性判据**（把上式接到已有机制上）：

```
设计已有 11 §2.6 的"分片间 JS 散度上账本" ⇒ 它就是 Γ 的可测代理
判据： 实测 JS 散度 ⇒ 估计 Γ ⇒ 代入 6LΓ ⇒ 若该邻域已大于"可接受精度"
       （由 Probe 的 MDE（第三轮推导 13）给出噪声地板）
       ⇒ plan() 报 ROOM_TOO_HETEROGENEOUS（warn），建议：缩分片 / 加共享池 / 加聚类
```

**诚实边界（Wang et al. 2022）**：上面的界用"梯度差异 Γ"是**悲观**的；
真正决定收敛的是"**最优点处的平均漂移 ρ = ‖G(θ*)‖**"，实测常比 Γ 小几个数量级。
⇒ 判据应优先用 **ρ 的实测代理**（`Probe` 在连续轮次上的**损失方差不减项**），
**Γ/JS 散度作为上界兜底**。这条必须写进推导，否则会把大量"其实很健康"的房间误判为异构。

### 推导 19：容差对拍的累积攻击面（慢速同向投毒）

**现状**：INV-7「跨设备权重比较用容差 1e-3」；09 §6「共识探针复算，比对 θ 收敛方向（1e-3 容差）」。

**攻击**：攻击者每轮只注入 `δ`，使 `‖δ‖/‖Δ_honest‖ ≤ 1e-3 − ε` ⇒ **单轮永远不可见**。

```
R 轮累计（同向）： ‖Σ_{t=1}^{R} δ_t‖ ≤ R·δ
⇒ 检测阈值若作用在**逐轮**，则攻击面 = 容差 × 轮数
⇒ 等价地：**有效容差必须随轮数收紧**
     δ 独立随机： tol_eff(R) = tol/√R       （随机游走 ⇒ √R）
     δ 系统性同向： tol_eff(R) = tol/R       （漂移 ⇒ R）
```

**数值示例**：`tol = 1e-3`，R=1000 轮。
逐轮判定 ⇒ 攻击者可累计约 `1000 × 1e-3 = 1.0`（相对尺度的 100%！）；
累计判定（系统性）⇒ 单轮必须 < 1e-6 才不被发现。

**修复（INV-26 / FED-V22）**：

```
累计偏差侦探（cumulative deviation detector）：
  对每个节点维护 Update 序列对**全局轨迹**的时间序列残差 r_t（非单轮范数）
  检测统计量： CUSUM(r) 或 滑窗均值/方差比
  超阈值 ⇒ 记 SLOW_POISON_SUSPECT 并 quarantine（09 §6）
同一条统计量同时是"SDC 缓慢漂移"的检测器（11 §11.7 的连续版）
```

注意与第三轮 INV-21（评测统计）**不是同一件事**：那条管"结论是否显著"，
这条管"**节点是否在缓慢地、每轮都合法地**把模型拖走"。

### 推导 20：验证者困境的期望收益不等式与不可能性

**收益不等式**：诚实复算成本 `c`，抓到作弊的奖励 `r`，作弊先验比例 `μ`。

```
E[U_复算] = μ·r·Pr(复算能定罪) + (1−μ)·0 − c  =  μ·r_eff − c
⇒ 复算 iff  μ > c/r_eff
⇒ 作弊稀少（μ→0）⇒ 理性验证者**不复算** ⇒ 作弊变有利 ⇒ μ 上升 ⇒ …
⇒ 只有混合策略均衡（Conway et al. 2024 对 opML 的结论）
```

**不可能性定理（Zhao et al. 2024, arXiv:2406.01794）**：

> 当 ① 诚实证明总能通过验证 ② 诚实验证的成本严格为正
> ⇒ **不存在**使 prover 与 verifier 同时诚实的**纯策略 Nash 均衡**。

**本设计正落在这个适用域**：

| 定理前提 | 本设计对应 |
|---|---|
| ① 诚实证明总通过 | 诚实节点的 Update 在容差内必过（INV-7） |
| ② 验证成本为正 | 复算要在本节点重跑训练（09 §6「每 N 轮抽 1 节点复算」） |
| 奖励 | 只有声誉降权（09 §6 声誉层）——**不是可转移的收益** |
| 频率 | 自愿、每 N 轮、1 个节点 ⇒ 被抽中概率可预测 |

⇒ **"默认关、可开"的共识探针在对抗档（L2/L3）不能指望自愿执行**；
更不能把"没人复算"当"默认通过"（沉默默认 = 验证者困境的标准表现）。

**修法（照抄 CTF 一脉 / ADR-031）**：

1. **复算是协议义务，不是自愿**：聚合端**随机指派**验证任务，被指派者不复算 ⇒ 记 miss
   （既有 MAX_MISSES 思路的泛化），**不是"沉默通过"**（扣留检测）；
2. **旗标（Capture-the-Flag）**：聚合端在某一轮 broadcast 里**注入一个可验证的偏离**
   （如故意篡改低位的 θ，或指定一个"应当被检出"的合成 Update）——
   **诚实时也总有活干**，报酬不再是"抓到作弊"而是"接住了任务"，绕开 μ→0 的困境；
   旗标轮的结果**必须丢弃**，不得污染真实模型（与 F-INV-4 单一权威配合）；
3. **PoL 的警示（Fang et al. 2022）**：PoL/Duplicated-execution 类"复算即验证"
   **已被证明可被便宜地 spoof**（跨配置可复现的攻击）。
   ⇒ 09 §6 提到的"乐观可验证训练（arXiv:2403.09603）"必须标注
   **"其安全性依赖学习理论中尚未解决的问题"**，不能作为可信承诺；
4. 诚实边界：以上只把"不能靠自愿"这件事说清楚，**不承诺消除作弊**（ADR-005 立场不变）。

## 4. 明确不做 / 暂缓（防范围膨胀）

- **不做**密码学级拜占庭共识（保持工程级：探针 + 账本 + 鲁棒聚合 + 声誉）；
  但**必须**把"工程级到底覆盖多少比例"写成数字（ADR-029），否则是含糊其辞。
- **不做**代币/抵押式激励（09 §9 立场不变）——因此 ADR-031 只能靠"义务化 + 旗标"
  这个**无货币**版本，且必须诚实标注：它的强度低于有抵押的方案。
- **不做**纠删码的全套经济模型（不引入 Filecoin 式存储市场）；
  ADR-034 只要"**有人在存 + 丢了能发现 + 缺副本能重建**"三件事。
- **不承诺**消除慢速投毒（推导 19 只把检测面从"逐轮"改成"累计"，
  真正的对抗性隐蔽投毒仍是开放问题）。
- **不重开**第一至三轮已定决策（本轮的每一条都是**补边界**，不是**改方向**）。
