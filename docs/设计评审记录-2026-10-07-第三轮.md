## 2. 六个新推导（可复算）

### 推导 9：自愿参与是选择偏差，不是 staleness

**设第 t 轮实际到达集 S_t 由各节点"此刻空闲且幸运"决定，单节点参与率 q_z，
总体 q = Σp_zq_z。朴素聚合估的是 E_{z∼S}[p_z∇f_z]，而真要的是 Σp_i∇f_i：

```
偏差量 = Σ_i (q_z(i)/q − 1)·p_i·∇f_i
        ↑ 参与率高于平均身份的项被系统性放大
```

数值例：PC（算力占比 p=0.85、常在 q=1.0）vs 手机（p=0.15、q=0.5）：
PC 权重 = (1/0.925)/1 ≈ 1.08，手机 = (0.5/0.925)/0.5 ≈ 1.08——**看似抵消；
但若手机数据强 non-IID**（p 是它的"份额"不是它的"代表性"），它的有效话语权
从 15% 掉到 ~8%，而 PC 的相应升到 ~92%——正是 09 §5.0 已防的"heterogeneity
amplification"的**选择维版本**（AC-AFL 打的是时间频次，这里打的是**入场概率**）。

修正（IPW）：`w_i ← w_i / E[q_z(i)]`。**同质档 q≡1 默认关**（等齐即全员），
异步档默认开。落点：09 §5.0.1 + FED-V18。

### 推导 10：shard 同伴数的可用性概率模型

单 peer 每轮失效率 q（浏览器 churn 估计 q∈[0.05,0.3]：切后台/省电/杀浏览器），
m 个 peer 组成的 shard（层切分/流水线 stage/专家组）本轮**可用**概率：

```
avail(m) = 1 − (1 − q)^m
```

| m | q=0.05 | q=0.15 | q=0.30 |
|---|---|---|---|
| 1 | 95% | 85% | 70% |
| 2 | 90% | 72% | 49% |
| 3 | 86% | 61% | 34% |

关键读数：**m 从 2→3，q=0.15 时可用性掉 11 个点（72%→61%），q=0.30 时掉 15 个点
（49%→34%）**；而 m 从 1→2 只掉 3/13 个点。边际收益递减快、边际成本递增
（§5.1.2 说的"整 shard 重分配"随 m 放大）。⇒ `plan()` 判据（09 §5.1.0.1）：
关键路径 stage 默认 m≤2、q>0.05 时 m=1；专家切分可 m=1（专家间天然冗余）；
**吞吐不足用"更多互不相交的 shard"而不是"更胖的 shard"**。

### 推导 11：gossip 共识的稳态边界

无中心两两合并的更新满足 θᵢ(t+1) = Σ_j W_ij(t)θ_j(t)（W 行随机/双随机）。
Boyd 式 gossip 平均的标准结论：

```
E‖θᵢ(t) − θ̄‖²  →  O( λ₂^t )，   共识时间 T ≈ (1/λ₂)·log(1/ε)
```

λ₂ 是混合矩阵次大特征值（谱隙）；m 个 peer 的环/网格拓扑 λ₂ ≈ 1 − c/m²
⇒ **T 随 peer 数上升**，浏览器 churn 下 peer 集几乎无稳态可言。
三条设计后果（落 09 §5.0）：

1. **稳态 ≠ 全局均值**：无中心输出不可称为"公共模型"；
2. **affinity 加权不收敛到全局目标**：只收敛到各自数据邻域的稳态
   （正好是 Chisme 的本意——通用知识 + 特定知识，不是"一个 θ"）；
3. ∴ 生产路径铁律：**公共模型产出必须过聚合端**（barrier/bounded-stale），
   gossip 仅作 peer 子群内部的低层同步。

### 推导 12：信任锚（TS）的方向 SNR 与 E_r 标定

FLTrust 式 TS 只用**方向**（cos），与幅值无关；但方向本身有抽样噪声：

```
σ_cos ≈ (1 − ρ)/√(b·E_r)
```

ρ=相邻步更新夹角的相关性（≈0 保守），b=锚 batch，E_r=参考训练步数。

| E_r | 4 | 8 | 16 | 32 |
|---|---|---|---|---|
| σ_cos | 0.177 | 0.125 | 0.088 | 0.063 |

边界：σ_cos 必须 **≪ 诚实节点间更新夹角的离散度**（跨策略/跨数据通常 0.3~0.7）
⇒ E_r=8~16 即进入"噪声 ≪ 信号"区。成本占比 `E_r·t_agg/Σp_iE_it_i` 在 N≥4 时 <5%。
落点：09 §5.7 的 E_r 标定规则（原只有"一轮参考训练"没说多少步、也没说噪声从哪来）。

### 推导 13：探针功效——多少 item 才检得出多少改动

比率型原子能力分数（accuracy/通过率）在 n 个 item 上的抽样噪声
σ≈√(p(1−p)/n)；两模型**未配对**差的 MDE（最小可检出效应，α=0.05、power=0.8）：

```
MDE ≈ (z_{α/2}+z_β)·√( p(1−p)·(1/n₁ + 1/n₂) )
```

| n（每臂） | 32 | 100 | 200 | 512 |
|---|---|---|---|---|
| MDE（p=0.5，未配对） | 35.0% | 19.8% | 14.0% | 8.8% |

三条可复算读数：

1. **n=200 的裸差 ≈±5%（1σ，两臂未配对差）** ⇒ 任何 <14% 的"能力提升/退步"在单轮探针上
   **不可与噪声区分**——而贡献分 φ_i、credit、`Finding` 的结论全部建在这上面；
2. **配对（CRN：同一批 item、同随机种子、同 few-shot 序）**把 Var(Δ) 从
   2σ² 压到 2σ²(1−ρ_pair)（典型 ρ_pair≈0.4~0.6）⇒ 同 n 下 MDE 再降 ~20~30%；
3. ∝ 1/√n ⇒ **n 翻 4 倍才把 MDE 减半**——"想检出 1% 的效应"未配对要 n≈3.3 万 item/臂
   （配对 CRN、ρ=0.5 也要 n≈1.6 万），
   浏览器一轮分钟级评测做不到。**所以设计承诺必须写"能检出多小的效应"，
   而不是"能评测"**。落点：INV-21/ADR-025 + `EVAL_UNDERPOWERED` +
   COMMONS-V17（探针池规模必须与声称效应匹配，否则拒收）。

### 推导 14：低秩反传捕获多少梯度能量（Eckart–Young）

GaLore 把梯度/优化器状态投影到 SVD top-r 子空间 U_r，子空间外残差：

```
residual(r) = Σ_{i>r} σ_i² / Σ_i σ_i²        （Eckart–Young–Mirsky）
```

LLM/Transformer 梯度谱的实证衰减快（LoRA 一脉反复观察到"大奇异值占绝大多数能量"）
⇒ r=64 时 residual 通常 <1%；r=16 时约 2~5%。STR-V16 因此取 **1%** 作回退阈值
（超阈值 ⇒ `APPROX_SUBSPACE_TOO_WIDE` → 回退全量反传），而不是拍脑袋的 r=8/16。

> 诚实边界：残差是**能量**界，不是收敛性保证；子空间漂移需周期重算 SVD
> （落在 07b §4 缺陷册的"投影残差随训练漂移"行）。

## 4. 明确不做 / 暂缓（防范围膨胀）

- **不做**个性化联邦内环（开放问题㉑ 默认 b：全局 θ + 本地 adapter；clustered FL
  只作 gossip affinity 的研究级对照）。
- **不做**配比玄学的解法（ADR-026 只让它可复现/可归因/有上限；Data Mixing Laws
  arXiv:2403.16952 是离线研究件，不进生产路径）。
- **不做**学习型代价模型/e-graph 融合的承诺（06 §2.1 登记为可选增强；
  WebGPU profiling 语料稀缺，先让静态成本注解过 LANG-V5）。
- **不宣称**探针能"杜绝"刷分/偏置（R-42/R-46 立场不变：只保证**量出噪声、按噪声下结论**）。
- **不追**后门攻防军备竞赛（ADR-027 只部署两道便宜对策；覆盖不到的数据投毒/
  慢速递归毒化仍归鲁棒聚合 + 抽样重算）。
- **不进** pFL/Ditto 类协议原语（㉑）；合成数据治理规则随㉒开放前排期。
