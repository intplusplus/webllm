# 07b · 训练算法目录

> 前置：07 学习策略层（Learner 抽象、四个一等维度、SyncSpec）。
> 定位：**本设计"训练算法无关"的完整编目**。约 35 个算法，按四个维度
> （`signal` / `depends` / `emits` / `maturity`）编目，每个标注：
> 已被证实的规模与场景、通信语义、同步形态、已知缺陷、来源。
>
> **读法**：这不是"算法大全"炫技，而是**可实现优先级清单**。
> 每个条目都回答一个问题：**它在本项目（浏览器 + 异构联邦）里值不值得实现，为什么。**

## 2. 按本项目价值的优先级排序（可实现清单）

不是"算法越好越先做"，而是"**对本项目的结构性问题最有杠杆**"。

| 优先级 | 算法 | 理由 |
|---|---|---|
| **P0（必须）** | backprop + AdamW/Muon、recompute、DPO | 生产默认 + 现有 trainer 的自然演化 |
| **P1（异构关键）** | **ES（OpenAI-ES → EGGROLL 低秩档）**、**ZO（MeZO → 受限子空间）**、**局部学习/PPLL 块** | 覆盖"跑不动反传的设备"与"低带宽场景"，且 `perturb`/`local-delta` 通信量极低 |
| **P2（联邦关键）** | DiLoCo/FedProx、模型汤 + 亲和 gossip 合并、EWC | 联邦专用漂移修正与合并；公地 fork/merge 的基石 |
| **P3（场景扩展）** | reinforce/PPO、VI/SGLD、前向模式 AD、MGRIT 近似档 | RL 与不确定性；`approx`+回退模式的第二个实例 |
| **P4（研究预留）** | 预测编码、EqProp、FF、NSGA-II 多目标、PBT | 只为**可表达性**；`plan()` 默认不选，实验档可开 |
| **不做** | 目标传播、合成梯度 | LM 上不佳 / 无扩展证据 |

## 3. 按"联邦友好度"排序（通信语义视角）

这是本目录与任何"算法大全"的根本区别：**按要交换什么排序，而不是按数学排序**。

```
通信量从低到高：

  perturb（seed + 标量）      ← ES / CMA-ES / EGGROLL / ZO / SPSA     【最低】
  local-delta（本层/本块）     ← FF / PPLL / 局部规则 / Hebbian
  delta（可稀疏/量化）         ← 任何本地训练后的差 / DiLoCo
  posterior（后验参数）        ← VI / MCMC
  grad（稠密全参数）           ← backprop / forward-mode / REINFORCE   【最高】
  merged（整模型，但无中心）    ← gossip / 模型汤 / Chisme
```

> **设计推论**：在"几百个浏览器 peer + 低带宽"的场景里，
> **优先级最高的不是"效果最好"，而是"通信量最低"**。
> 这正是 EGGOLL 的种群独立性 + 标量 fitness 通信在本项目里
> 比在单机大集群里**更有价值**的原因——单机上通信便宜，浏览器上通信是稀缺资源。

## 4. 已知缺陷与失效模式登记册

| 算法/路线 | 已知缺陷 | 本设计的应对 |
|---|---|---|
| ZO 全参扰动 | 高维方差大；**模型越大越不稳定** | 受限子空间硬约束（07 §3.2） |
| ES 无结构扰动 | 算术强度低，GPU 上不可行 | **低秩结构化扰动**（EGGROLL） |
| 局部学习 | **可能丢弃下游所需信息** | `approx.detect` + 信息保持验证 |
| MGRIT 不精确梯度 | 系统性偏差，损害接近极值的收敛 | **偏差检测 + 回退精确算法** |
| 异步 × 非 IID | **异质性放大**：快节点主导全局模型 | fairness 加权 + latest-all + affinity |
| backprop 异步 | 梯度 staleness 伤害收敛 | 默认 barrier-round；`STALENESS_MAY_DIVERGE` 警告 |
| Hebbian | 仅卷积网络验证，与 Transformer 差异大 | 只作可表达性保留，不提位 |
| 模型合并 | 排列对称性导致平均失效 | 合并前消排列（Git-Re-Basin 类） |
| 持续学习 | 灾难性遗忘 | EWC/SI/LwF 作为配菜策略 |
