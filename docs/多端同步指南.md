# 多端同步指南（本地 × Gitee × GitHub）

本机仓库同时挂两个公开远端：**Gitee**（国内访问快）与 **GitHub**（国际访问快），
以「本机 main 为唯一事实源」的小时间隔自动互推，分叉时停机等人工处理。

## 远端配置

| remote | URL | 用途 |
|---|---|---|
| `origin` | `git@gitee.com:tolm/webllm.git` | Gitee（已公开） |
| `github` | `git@github.com:<user>/webllm.git` | GitHub（公开） |

每台电脑一把专用 ed25519 密钥（本机：`~/.ssh/id_gitee`、`~/.ssh/id_github`），
已分别添加到对应平台 → Settings → SSH Keys。**脚本不保存任何令牌**。

## 本地已有的一切

- `scripts/sync-remotes.mjs`：同步执行体（零依赖）
- `.gitignore` 已含 `.sync/`：日志目录，不入库
- 计划任务 `webllm-sync`：每小时以当前用户身份跑一次同步
- （可选）harness 侧还有一个每小时的提醒，仅在异常时汇报，平时零打扰

## 日常使用

手动同步（任何时候）：

```bash
node scripts/sync-remotes.mjs              # 正常同步（fetch → ff → push 双远端）
node scripts/sync-remotes.mjs --dry-run    # 只看本地/远端领先落后，不联网写操作
node scripts/sync-remotes.mjs --remotes=origin   # 只同步 Gitee
```

看日志：`.sync/sync.log`（每次一行摘要）。

**同步前会自动检查**：工作区有未提交改动 / 不在 main 分支 → 拒绝同步（退出码 3），
先 `git commit` 或 `git stash`。

## 第二台电脑接入（10 分钟）

```bash
# 1. 克隆（任选一个远端，之后补上另一个）
git clone git@gitee.com:tolm/webllm.git webllm && cd webllm

# 2. 生成本机专用密钥并分别加到两个平台
ssh-keygen -t ed25519 -C "你的备注@webllm" -f ~/.ssh/id_gitee   # 公钥 → Gitee → Settings → SSH Keys
ssh-keygen -t ed25519 -C "你的备注@webllm" -f ~/.ssh/id_github  # 公钥 → GitHub → Settings → SSH Keys

# 3. ~/.ssh/config 追加两段（Windows: %USERPROFILE%\.ssh\config）
#    Host gitee.com / HostName gitee.com / User git / IdentityFile ~/.ssh/id_gitee / IdentitiesOnly yes
#    Host github.com / HostName github.com / User git / IdentityFile ~/.ssh/id_github / IdentitiesOnly yes

# 4. 补第二个远端（HTTPS/SSH 均可，随后可 git remote set-url 换 SSH）
git remote add github git@github.com:<user>/webllm.git

# 5. 装计划任务（每小时）
schtasks /Create /TN "webllm-sync" /SC HOURLY /RL LIMITED /F ^
  /TR "cmd /c node \"%~dp0sync-remotes.mjs\" >> \"%USERPROFILE%\.webllm-sync.log\" 2>&1"
```

## 分叉处理（自动流程会退出码 2 并停手）

两台电脑各自提交后，先同步的那台推送成功，后同步的那台就会检测到分叉：

```bash
git log --oneline main..github/main     # 看远端多了什么
git merge github/main                   # 或 git rebase，解决冲突
node scripts/sync-remotes.mjs           # 重跑同步
```

## 已知边界

- **harness 沙箱内 git 走不了 SSH**（git→ssh 子进程被拦）：在 DSH 会话里同步需用
  HTTPS 内建传输 + 一次性 URL（令牌不落盘）；你本机终端里 SSH 一切正常。
- 同步只动 `main` 分支；其他分支各自 `git push -u` 到具体远端即可。
