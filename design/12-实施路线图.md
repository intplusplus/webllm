# 12 · 实施路线图

> 前置：02 架构总纲（现状映射）。
> 定位：每阶段**独立验收**，任何一阶段失败都可回退而不拖死全局。

---

## 0. 总原则

1. **对拍驱动**：每个迁移必须"同输入同输出（容差内）"，禁止顺手改底层。
2. **不变量优先**：先让新的不变量可自动检查，再写新功能。
3. **联邦后置但接口先行**：联邦协议在 P7/P8 才落地，但 `Update`/`specHash` 的
   **数据契约从 P0 就存在**，避免事后返工。
4. **每阶段都能停**：任何阶段结束时，系统都是**可发布状态**（哪怕能力不全）。

## 3. 里程碑与北极星（01 §4 的落地刻度）

| 里程碑 | 达成标志 |
|---|---|
| **M-IR** | Spec IR 落地，AI 可盲测生成合法模型 |
| **M-COMPILE** | 组件树模型对拍一致、吞吐退化 <10% |
| **M-STRATEGY** | 同一模型可用 ≥3 种策略训练并都收敛 |
| **M-HETEROGENEITY** | 反传节点 + 零阶节点真机混合训练跑通 |
| **M-PUBLIC** | 公地可 fork/merge/挂 adapter，账本可审计 |
| **M-WEAKEST** | **最弱设备仍能贡献**（接入成本 ≤3 步的最后一格） |

## 4. 每阶段的"停止条件"（何时该停下来想）

| 信号 | 含义 | 动作 |
|---|---|---|
| 对拍断裂且无法在两轮内修复 | 迁移方式错（不该顺手改底层） | 回退该阶段，改方案 |
| 新阶段需要改动上阶段已冻结契约 | 分层切错了 | 回到 02 分层图重切 |
| AI 回路的成本高于手写 | LANG 验收失败 ⇒ M2 护城河不成立 | 重审 04 |
| Update 协议表达不了某种策略 | 07/09 接口塌缩成"梯度假设" | 重审 09 §4 |
| 异构混合被证明不可行 | 退化为同质档 + 更强的降级阶梯 | 13 更新风险登记 |

## 5. 快照与恢复验收（P8，来自 14 §2.3）

| 编号 | 场景 | 标准 |
|---|---|---|

## 6. 工作量提示（不给时间估计，只给结构）

最大工作量集中在 **P1/P2**（35 个 kernel 的契约化 + 自动排布）与
**P5/P7**（策略层 + 异构联邦）。P3/P6/P8 是"广度"工作，风险低但项数多。
**P0 不可跳过**——IR 一旦返工，上层全部重写。
