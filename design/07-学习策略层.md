## 1. 本层的存在理由

现有框架（尤其 PyTorch）有一个**未明说但极其深刻**的假设：

> **模型 = 一个能被反向微分的东西。于是"训练"被实现为"反向传播"，
> 而反向传播成为框架的本体，而非一个可选策略。**

这个假设的代价，在本项目关注的场景里**全部显形**：

| 代价 | 具体表现 |
|---|---|
| 排除一类系统 | 不可微/离散/黑盒/符号系统**没有梯度可返**，但它们仍可被优化 |
| 焊死设备能力 | 弱设备跑不动反传 ⇒ 只能退出，而不能"换个方式参与" |
| 照搬枷锁 | 想在 PyTorch 里做 ES/Hebbian/FF，全靠外挂补丁，与框架语义打架 |
| 无法异构协作 | 反传假设"人人都有梯度可传"，与联邦异构现实冲突 |
| **通信结构被绑死** | 反传的梯度是**稠密全参数**量，与"低带宽/高延迟"的联邦现实冲突 |

**本层的设计**：把"怎么学"从"模型是什么"里拿出来，变成**可枚举的策略**，
每个策略：**声明需求 → 消费能力 → 产出语义无关的更新**。

```
① 计算（IR）     纯 forward，不强制可微，可含 nondiff 节点
② 学习（本层）   Learner：消费 (model, objective, data, swarm) → 产出 Update
③ 协作（09）     消费 Update → 聚合 → 新 θ
```

### 1.1 2026 年的新证据：ES 已经在十亿参数级有竞争力（★ 改写 M5 的关键）

2026 年的两项进展实质性改变了格局，**但改变的方式不是"ES 比 BP 好"**：

| 成果 | 关键事实 | 对本设计的意义 |
|---|---|---|
| **EGGROLL**（Oxford FLAIR 2026） | 把个体扰动结构化为 **rank-r 矩阵** ⇒ 十亿参数级大种群下**百倍加速**，达**纯批量推理吞吐的 91%**；从零预训练 int8 RNN LM，种群 2→1,048,576；某任务 bits/byte **3.40 vs 反传 SGD 3.58** | **"种群成员独立 + 只传标量 fitness"** 是天然最低通信的训练算法；低秩扰动是高维可行性的关键 |
| **ESSA**（2025） | CMA-ES 作用在 **SFT 初始化后的 LoRA 奇异值**上，无梯度完成对齐，**比 GRPO 收敛更快、更数据高效** | 降维（LoRA/子空间）是 ES 用于大模型的必要条件 |
| **PPLL**（2024） | 局部学习块各自独立反传 ⇒ **不必等后续模块**即可开始；4 GPU 上 ViT/ResNet 训练加速 162%/33% | 局部学习 ⇒ **无跨设备梯度依赖** ⇒ 天然流水线跨 peer |
| **MGRIT 层并行**（2026） | 用**不精确梯度**换取层维并行；发现偏差会损害收敛，于是**检测偏差过大时回退到串行/提高精度** | **近似 + 偏差检测 + 回退**是一等模式，不是补丁 |

⇒ **由此确立本层的四个一等维度**（§2）：`信号来源`、`依赖结构`、`通信语义`、`近似与回退`。
BP 只是这四个维度上的一个取值组合——**不是特例，也不是默认特权，而是被平等对待的一个点**。

## 2. Learner 抽象：四个一等维度

```ts
interface Learner {
  id:          StrategyId
  // ① 信号来源：算法从哪里得到"哪个方向更好"
  signal:      'gradient' | 'fitness' | 'local-error' | 'logprob' | 'preference' | 'reconstruction'
  // ② 依赖结构：算法需要什么才能算一步
  depends:     'end-to-end' | 'block-local' | 'layer-local' | 'population-independent' | 'env-coupled'
  // ③ 通信语义：一步里要交换什么（决定联邦友好度）
  emits:       UpdateKind          // grad | delta | perturb | local-delta | posterior | merged
  // ④ 近似与回退：是否用近似信号，如何发现近似失效
  approx?:     { kind, detect: DiagCode, fallback: StrategyId }
  // 其他
  requires:    OpCapability[]
  phases?:     Phase[]
  state:       StateSpec            // moments | svd-proj(lowrank-bp) | population | replay | ema | ef-residual | none
  sync:        SyncSpec             // §4 异步一等
  cost:        { mem, fwdPasses, bwdPasses, comm }
  maturity:    'production' | 'niche' | 'research' | 'rejected'
}
```

### 2.1 维度③「通信语义」是联邦友好度的决定因素

这是本设计与众不同的地方：**不是按"用什么数学"分类算法，而是按"要交换什么"分类**。

| `emits` | 交换内容 | 通信量级 | 哪些算法 |
|---|---|---|---|
| `grad` | 稠密全参数梯度 | **最大**（≈ 参数量） | backprop、forward-mode |
| `delta` | 参数差（可稀疏/量化） | 中（可压缩） | 任何本地训练后的差 |
| **`perturb`** | **一个 seed + 一个标量 fitness** | **极小（O(1) 字节）** | **ES / CMA-ES / EGGROLL / ZO** |
| `local-delta` | 仅本层/本块参数 | 小（可分块） | 局部规则 / FF / PPLL |
| `posterior` | 后验参数 | 中 | VI / MCMC |
| `merged` | 合并后的模型（gossip） | 大但**无中心** | Chisme 式亲和合并 |

> **关键洞察**：`perturb` 只传**标量**。EGGROLL 因此能把种群扩到百万级而通信不炸——
> 这正是"几百个浏览器 peer 一起训一个模型"最需要的性质。
> **联邦友好度 = f(emits)，而不是 f(数学优美度)。**
> **对偶代价（★ 2026-10 第二轮评审，推导 8）**：`perturb` 把通信压力转成**聚合端算力**
> （每更新重建方向 O(P)）⇒ 判定式 `S·P·4B ≤ agg_compute_budget` 进 `plan()` 预算
> （STR-V14）；`local-delta`/adapter 路径还要处理**秩异构**：允许各节点按能力自选
> adapter 秩，聚合端 SVD 重分/加权堆叠合成全局（HetLoRA/FlexLoRA/FFA-LoRA，11 §3.2）。
>
> **压缩与 `emits` 正交（★ 第四轮评审，推导 17 / ADR-032）**：`grad`/`delta` 走网络时
> 可施加稀疏/量化，但**有偏压缩器（top-k/sign）必须带 error feedback 才收敛**——
> 否则偏置固定、不随 T 衰减（09 §4.4）。EF **不改变 `emits` 语义**，故不影响
> 策略选择与 INV-11；但它引入**跨轮状态**（残差），必须与 `state` 一起进 `Snapshot`（INV-24）。
> ⇒ `Learner.state` 的 `StateSpec` 增一格：`'moments' | 'svd-proj' | 'population' |
> 'replay' | 'ema' | 'ef-residual' | 'none'`。

### 2.2 维度②「依赖结构」决定能否跨设备

| `depends` | 含义 | 跨设备可行性 |
|---|---|---|
| `end-to-end` | 需要完整前向+反向链 | **难**：要么同步等最慢的，要么忍受 staleness |
| `block-local` | 块内自反传，块间只传激活 | **好**：PPLL 已验证，天然流水线 |
| `layer-local` | 只更新本层 | **好**：通信最低，但可能丢下游信息（已知缺陷） |
| `population-independent` | 成员互不依赖 | **最好**： embarrassingly parallel |
| `env-coupled` | 需要与环境交互 | 中：rollout 可异步，但需 `Env` 效应声明 |

### 2.3 维度④「近似与回退」：从 MGRIT 学到的一等模式

MGRIT 的核心教训：**用不精确梯度换并行性，会产生系统性偏差，损害接近极值时的收敛**；
解法是**检测偏差过大 ⇒ 回退到精确算法**。

⇒ 本设计把它升为通用模式：

```
approx := {
  kind:    'inexact-gradient' | 'zo-estimate' | 'local-surrogate' | 'low-rank-subspace'
  detect:  'BIAS_TOO_LARGE'        // infer()/profile() 可判：估计量与真实量的一致性
  fallback:'backprop'              // 回退目标（生产级策略）
}
```

规则：任何非生产级策略都必须声明 `approx`；`plan()` 在检测到 `BIAS_TOO_LARGE` 时
**自动回退**到 `fallback`，而不是让训练静默劣化。
这直接服务 ZGCM 式事故（"loss 还在降，模型却退步"）的自动兜底。

## 3. 策略清单与成熟度分级

**诚实边界（2026 研究综述的结论仍然有效）**：**没有任何非反传方法能在
"从头预训练超大规模 LLM"这一核心场景上全面挑战 BP**；
ICML 2026 量化代价：同等内存下 BP+激活检查点**准确率高 31.1%、收敛快 34.8%**。

⇒ 但 2026 的新证据**实质性收窄了这个差距的适用范围**：ES 在**低秩扰动 + 大种群 + 只传标量**
的条件下已达十亿参数级竞争力（EGGROLL），且**在若干设定下优于反传**。
所以正确的表述不是"BP 永远赢"，而是：**BP 在生产默认位上，ES 在其结构性优势的场景上
（无梯度/非可微/极低通信/超大规模种群）已经是真正的替代而非凑合**。

完整编目见 **07b**。此处只列骨架：

| 级别 | 策略 | `signal` / `depends` / `emits` | 立场 |
|---|---|---|---|
| **生产级** | `backprop` | gradient / end-to-end / grad | **默认** |
| **生产级** | `forward-mode` | gradient / end-to-end / grad | 低维输出、省激活 |
| **生产级** | `reinforce` | logprob / env-coupled / grad | 离散策略 |
| **生产级** | `variational` | logprob / end-to-end / posterior | 不确定性 |
| **场景级（省优化器显存）** | **`lowrank-bp`（GaLore/Q-GaLore 档）** | gradient / end-to-end / **grad（低秩投影）** | **全参数梯度 + SVD 低秩优化器状态**：内存门槛从"跑得起 AdamW 2×P fp32"降到 r×r 投影（§3.3） |
| **场景级（结构性优势）** | `es`（含 EGGROLL 低秩档） | fitness / population-independent / **perturb** | **联邦原生**：只传标量、可百万种群、能吃非可微/离散/int8 |
| **场景级（有规模上限）** | `spsa`/`zo` | fitness / population-independent / perturb | 仅限小模型或**受限子空间**（§3.2） |
| **场景级** | `local`/`forward-forward`/`ppll-block` | local-error / block-local / local-delta | 低通信跨设备流水线（PPLL 实证） |
| **研究级** | `equilibrium-prop` | local-error / end-to-end / delta | 预测编码可与 BP 相当（中小规模） |
| **研究级（有缺陷）** | `local` 贪心分块 | local-error / layer-local / local-delta | **可能丢弃下游所需信息** |
| **不采用** | 目标传播、合成梯度 | — | LM 上不佳 / 无扩展证据 |

### 3.1 M5 护城河的正确表述（承接 02 §3.5）

**「参与权平等，效果不平等」**——并且 2026 年后可以再多说一句：

> 在**结构性优势场景**（无梯度可返、非可微/离散/低精度、极低通信预算、
> 超大规模异构种群）上，ES/ZO/局部学习**不是凑合的替代，而是更合适的工具**。
> EGGROLL 的低秩 ES 已达十亿参数级竞争力，某任务 bits/byte 超过反传 SGD。

这两句话合起来才是完整的 M5：**BP 在生产默认位上不可替代；
但在联邦/异构/不可微的场景里，算法无关性给出的是 BP 给不了的参与权与通信结构。**

### 3.2 ZO/SPSA 的正确约束：不是"只限小模型"，而是"只限受限子空间"

2025-2026 的 ZO 进展一致指向同一个结论：**ZO 的困难是高维扰动方差，
解法是限制扰动子空间**——Sparse-MeZO（参数掩码，LLaMA-30B 单卡）、
ZO-Act（一次性激活低秩基，INT4 冻结权重）、ZO2（CPU offload，OPT-175B on 18GB）、
MeZO-GV/Greedy（用低损/高损扰动群构造导向向量）。

⇒ 约束改写为：

```
zo 仅允许在【受限子空间】上扰动：
   · LoRA/adapter 子空间，或
   · 一次性激活低秩基张成的子空间，或
   · 参数重要性掩码选出的子集，或
   · 小分片（层数/参数量低于阈值）
否则 infer() 报 ZO_SUBSPACE_TOO_WIDE
大分片 + 无受限子空间的弱设备 ⇒ 降级为 evaluator-only
```

### 3.3 内存受限的正确顺序：低秩反传优先于零阶（★ 第三轮评审新增，ADR-024）

2024–2026 的省显存训练路线把"内存不够"这个判断劈成了两半，此前本设计
（与多数工程直觉一样）把"内存不够 ⇒ 零阶/ES"当成一根轴，这是**错的**：

| 装不下的是什么 | 传统默认 | 正确工具（2024-2026 已届成熟） |
|---|---|---|
| **优化器状态**（AdamW 每参数 2×P fp32 = 8B/param） | 降级到无梯度 | **低秩反传（GaLore 系）**：SVD 投影把优化器状态压到 r×r，梯度仍是**全参数真实梯度** |
| **激活** | recompute | recompute（既有）或前向模式 |
| **两者都不够且不可微** | —— | 才轮到 ES / ZO（受限子空间） |

GaLore（arXiv:2403.03507）证明预训练 7B 在单卡 24GB 可行；Q-GaLore 进一步
量化到 4bit。同族的 Adafactor / Apollo / Adam-mini / LOMO 是这一档的
更轻变体（07b §1.1）。

⇒ **硬规则（进 07 §5 选择算法）**：`differentiable(ir) ∧ memAvail < memFor('backprop')`
时，**必须先试 `lowrank-bp`，再考虑 ZO/ES**。理由：它不改变 `emits`（仍 grad/delta）、
不改变 specHash、聚合与通信语义完全不变——**降级链条上代价最小的一格**。
`infer()` 对该策略额外校验：投影秩 r 必须声明；投影残差能量
`1 − ‖U₁ᵀg‖²/‖g‖²` 超阈值 ⇒ `APPROX_SUBSPACE_TOO_WIDE`（与 ZO 子空间校验同构）。

## 4. 同步性是一等维度：SyncSpec（★ 本版新增）

此前的联邦协议默认"轮次 + 软屏障"。用户明确指出：**必须对异步算法友好**。
异步不是降级模式，而是与同步**平级**的一等选择。

```ts
interface SyncSpec {
  mode: 'barrier-round'      // 每轮等齐（同质档默认）
      | 'bounded-stale'      // 允许落后 ≤ k 个版本，超过丢弃
      | 'async-event'        // 无屏障，事件驱动（peer 随时上报/拉取）
      | 'gossip'             // 无中心，peer 间互相同化
      | 'pipeline-overlap'   // 边训边传，激活在 peer 间流动（PPLL 式）
  staleness?: {
    maxLag:      number            // bounded-stale 的 k
    policy:      'drop' | 'dampen' | 'align'   // 过期更新如何处理
    fairness:    boolean           // 是否按"新鲜度 × 参与频率"加权（防快节点主导）
  }
  affinity?: {                     // gossip 模式：按数据亲和度加权合并
    metric: 'model-cosine' | 'loss-similarity'
  }
}
```

### 4.1 四种 staleness 策略（来自 2026 异步联邦研究）

| 策略 | 机制 | 来源 |
|---|---|---|
| `drop` | 落后超过 `maxLag` 的更新直接丢弃 | 经典 bounded-staleness（SSP） |
| `dampen` | 服务端对过期更新加**staleness 惩罚**，越旧权重越低 | APFA（2026）：等待时间 −71% |
| `align` | 用一小批**校准集**做跨版本语义对齐，再聚合 | AlignFed（2026）：版本感知分组 + 校准对齐 |
| `latest-all` | 每次聚合都取**所有 peer 的最新可用**更新 | AC-AFL：治"heterogeneity amplification" |

### 4.2 异质性放大（heterogeneity amplification）——必须防的失效模式

AC-AFL 指出的现象：**异步性 × 非 IID 数据 ⇒ 快节点贡献更频繁 ⇒ 系统性把全局模型
拉向它的数据分布**。在我的场景里这就是"最活跃的手机定义了公共模型"。

⇒ 三条对策（可组合）：
1. **fairness 加权**：权重 ∝ 新鲜度 × 参与频率（AlignFed）——**不是**只按样本数；
2. **latest-all**：每轮聚合纳入所有 peer 的最新更新，而非只纳入快节点的多次更新；
3. **affinity 感知**：gossip 模式下按模型余弦相似度推断数据亲和度，
   决定"吸收多少"（Chisme）——让同质节点多合、异质节点少合。

> **同步档的同款放大器（★ 2026-10 评审新增）**：即使 `barrier-round`，
> 时间预算截断也会让快节点每轮跑更多步，样本加权把慢节点按 **n²** 压掉
> （完整推导见 09 §5.5）。对策不是 fairness 加权，而是 **FedNova 步数归一化**：
> `Learner` 上报 `Update.steps`（本轮实际本地步数 E_i），聚合端重标定
> `s_i = E_ref/E_i`。**这是 Learner 的协议义务，不是聚合端的可选项**——
> 不报 steps 的 Update 在协议层即不完整。

### 4.3 每种算法的原生同步形态

| 算法 | 原生同步形态 | 说明 |
|---|---|---|
| backprop / forward-mode | `barrier-round`（可退化为 `bounded-stale`） | 梯度 staleness 会伤害收敛，故默认屏障 |
| **ES / EGGROLL** | **`async-event`（原生）** | 种群成员独立，谁先算完谁先报 fitness |
| ZO | `async-event` 或 `bounded-stale` | 同上，但要注意子空间一致性 |
| local / FF / PPLL | **`pipeline-overlap`（原生）** | 块间只传激活，天然异步流水线 |
| reinforce / VI | `bounded-stale` | rollout 长短不一 |
| gossip / 模型合并 | `gossip` | 无中心 |

⇒ **设计规则**：`plan()` 选策略时**必须同时选 sync 形态**；
若用户为 `backprop` 指定 `async-event`，`infer()` 应警告 `STALENESS_MAY_DIVERGE`。

## 5. 策略选择算法（按集群画像 + 同步形态）

`plan()` 与 AI agent 共用同一个决策函数（保证一致、可解释）：

```
function chooseStrategy(ir, peer, budget, syncMode):
  caps := peer.strategies ∩ caps(ir.graph)
  // 1. 生产默认
  if 'vjp' ∈ caps and peer.memAvail ≥ plan().memFor('backprop') and syncMode allows:
      return 'backprop'
  // 2. 结构性优势场景（按优先级）
  if not differentiable(ir) or peer.memAvail < memFor('backprop') * 0.5:
      // ★ 内存受限但可微时，低秩反传优先于零阶（§3.3）：
      //   GaLore 档把优化器状态压到 r×r（AdamW 要 2×P fp32），
      //   仍产出**全参数梯度**，通信语义与 backprop 相同（grad/delta）
      if differentiable(ir) and peer.memAvail ≥ memFor('lowrank-bp'): return 'lowrank-bp'
      if zoSubspaceFeasible(ir):   return 'zo'        // 受限子空间
      else:                        return 'es'        // 低秩扰动 + 大种群
  if budget.commKbps < threshold:  return 'local'|'forward-forward'   // 低通信
  if ir has nondiff/env nodes:     return 'es'|'reinforce'
  // 3. 研究档（需显式开启）
  if experimental: return 'equilibrium-prop'
  // 4. 兜底
  return 'evaluator-only'
```

`rationale`（人可读的理由链）是**可解释性的关键**：任何策略分配都能回答"为什么"。

## 6. 降级阶梯（能力不足时换角色，而非被抛弃）

```
全量反传 ──► 前向模式 ──► 低秩反传 ──► 块内局部学习 ──► 低秩 ES ──► 零阶（限受限子空间）──► 仅前向评估 ──► 聚合/中继
  (PC)       (省激活)    (省优化器    (省通信·PPLL)     (无梯度)      (黑盒·子空间受限)        (最弱设备)      (无算力也贡献)
                          状态·GaLore)
```

> **插入格的顺序依据（★ 2026-10 第三轮评审新增，ADR-024）**：
> 从"全量反传"到"零阶"之间原来直接从**省激活**跳到**无梯度**，缺了
> **"梯度仍然真实、只是优化器状态装不下"**这一大档设备（内存 256MB~1GB 的手机
> 恰好在这里）：GaLore（arXiv:2403.03507）与 GaLore 2 / Q-GaLore（arXiv:2504.20437）
> 证明全参数梯度 + SVD 低秩投影优化器状态可行，**数学上仍是 backprop**
> （`emits: grad`，通信与聚合语义完全不变、specHash 不变）——
> 所以它必须排在"换通信语义"的低秩 ES/局部学习之前。
> Eckart–Young 给出子空间外梯度能量的上界（推导 14，见
> `docs/设计评审记录-2026-10-07-第三轮.md`）：LLM 梯度谱快速衰减 ⇒ r=64 通常捕获 >99%。

> **末三格的顺序有讲究**：ZO 只适用于受限子空间（§3.2）；不满足就先降到
> **低秩 ES**（EGGROLL 证明它在低通信+大种群下更强），再不行才"仅评估"。
> **铁律（INV-11）**：降级不得改变 `specHash` 与参数形状——换个学习方式
> 仍然是"同一个模型、同一个 θ"。

## 7. Phase 的扩展（策略引入的新相位）

| 相位 | 用途 |
|---|---|
| `train` / `prefill` / `decode` | 既有（CED、MTP、dropout） |
| `sample` / `rollout` | RL/扩散采样 |
| `free` / `nudge` | EqProp 两相；FF 正负相 |
| **`positive` / `negative`** | Forward-Forward 的两相 |
| **`e-step` / `m-step`** | EM 类算法 |
| **`wake` / `sleep`** | wake-sleep / Helmholtz 机 |
| **`eval-only`** | 仅评估角色（降级阶梯末格） |

`annot.phase` 因此是**策略相关的**——`infer()` 检查"策略所需相位图里是否提供"。

### 7.1 数据调度是策略的一部分

`TrainerSpec.schedule` 表达"**阶段 × 数据配方**"（Marin Tootsie Roll 为参照）：

```
schedule := {
  localSteps, syncEvery, precision,
  stages: [{
    name, until?: number,
    on?: 'data-exhausted' | 'time-budget' | 'hardware-change' | 'peer-set-change',
    data: dataVersion, lr?, batch?, precision?
  }]
}
```

- 配方**版本化**（`dataVersion`）⇒ 进 `Snapshot`、进溯源 ⇒
  "配比玄学"不解决，但**配比必须可复现、可归因**。
- `data-exhausted` / `peer-set-change` 在联邦里是**常态**；
  反应式切换由外层编排器决定（03 §3 循环外置），IR 只声明阶段与配方。

## 8. 与 Update 协议的接口（07 ↔ 09 的契约）

```
Learner ──emits──► Update ──consumed by──► 聚合器（09）
```

`Update` 是**语义无关**的数据（09 §4）：`grad / delta / perturb / local-delta / posterior / merged`。
策略层**不关心**聚合怎么做，聚合层**不关心**信号怎么来的。
**这一条是"异构联邦"能成立的唯一接口**——若 Update 里塞了"梯度假设"，
整个异构设计立刻塌缩成 PyTorch 的形状。

## 9. 验收线

| 编号 | 指标 | 标准 |
|---|---|---|
| STR-V1 | Learner 抽象可无头实例化（Node 侧）并跑通 | 是 |
| STR-V2 | 每个策略在小模型上与参考实现对拍 | 反传对拍既有 trainer；ES/ZO 对拍 numpy 实现 |
| STR-V3 | 非反传策略**loss 确实下降** | 小 LM 收敛曲线（不求快只求降） |
| STR-V4 | `chooseStrategy` 在 5 个异构集群画像上输出可行组合 + rationale | 是 |
| STR-V5 | Update 序列化后能被 09 的聚合器消费 | 协议级自检 |
| STR-V6 | 降级任一档后 `specHash` 不变 | INV-11 自动化 |
| **STR-V7** | **`perturb` 通信量验证** | ES/ZO 一步只传 seed + 标量 ⇒ 通信量 O(1) 字节，与参数量**无关** |
| **STR-V8** | **异步容忍度** | 同一策略在 `barrier-round` 与 `async-event` 下都能收敛（后者允许更慢） |
| **STR-V9** | **近似回退** | 注入 `BIAS_TOO_LARGE` 后 `plan()` 自动回退到 `fallback`，loss 不劣化 |
| **STR-V10** | **fairness 加权生效** | 构造"快节点 + 偏斜数据"场景，全局模型不被单节点主导（AC-AFL 式失效被防住） |
| **STR-V11** | **受限子空间校验** | `zo` 在过宽子空间上被 `ZO_SUBSPACE_TOO_WIDE` 拒绝 |
| **STR-V12** | **steps 上报义务** | 每个 Learner 产出 Update 必带 `steps`（本轮实际本地步数）；缺失即协议不完整，`plan()` 拒收（09 §5.5） |
| **STR-V13** | **FedNova 对拍** | 快 20 步/慢 4 步场景：归一化前后有效份额与手算一致（与 FED-V9 同一场景，勿用同速测试充数） |
| **STR-V14** | **perturb 聚合端算力预算** | 构造 `S·P·4B > agg_compute_budget` 的房间 ⇒ `plan()` 拒绝星形 perturb 聚合并给出分层建议（与 FED-V13 同场景，勿复用同一构造） |
| **STR-V15** | **低秩反传保真** | `lowrank-bp` 在小 LM 上 loss 下降（STR-V3 同标准）；相对全量反传的最终 loss 差在容差内；`specHash` 与参数形状与全量档一致（INV-11） |
| **STR-V16** | **低秩子空间梯度能量** | 投影残差能量 `1−‖U₁ᵀg‖²/‖g‖²` 实测 ≤ 1%（r 取 plan() 建议值）；超 1% 时 `APPROX_SUBSPACE_TOO_WIDE` 被触发并回退全量（§3.3） |
| **STR-V17** | **有偏压缩的误差反馈（ADR-032）** | 同一 top-k 稀疏压缩下：**无 EF 实现**在固定步数后停在偏置邻域（loss 不再下降，与未压缩基线有稳定差距）⇒ 必须挂红；**有 EF 实现** loss 下降至与未压缩基线在容差内（§2.1 / 09 §4.4） |

> 标定值在 P2 阶段用同一批 agent + 同一批任务跑出基线后写入（不做先验承诺）。
